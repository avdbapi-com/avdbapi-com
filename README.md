## Quick start

**Run JavCMS on your own hosting.** It is free and source-available:

1. Create an empty database and a database user in your hosting panel.
2. Download the [latest release](https://github.com/avdbapi-com/javcms/releases/latest), upload the zip to your site folder and extract it.
3. Open `https://your-domain/install.php` and choose your catalogs: AVDB, xvidapi, both or later.
4. Sign in at `https://your-domain/javcms.php` and follow the checklist on the first page.

Big catalogs import faster from the command line, and every import continues where it stopped:

```bash
# size, time and storage target of the whole AVDB catalog
php tools/import.php --estimate --provider=avdb --scope=full
# create the import job, then run it (or let cron run it every 5 minutes)
php tools/import.php --start --provider=avdb --scope=full
php tools/import.php --run --max-minutes=4
```

Needs PHP 7.4 to 8.5 and MySQL 5.6+ or MariaDB 10.1+, on Apache, Nginx, OpenLiteSpeed or IIS. The full guide is in the [JavCMS repository](https://github.com/avdbapi-com/javcms#quick-install).

<a href="https://github.com/avdbapi-com/javcms/releases/latest"><picture><source media="(prefers-color-scheme: dark)" srcset="https://raw.githubusercontent.com/avdbapi-com/avdbapi-com/main/assets/badge-download-dark.svg"><source media="(prefers-color-scheme: light)" srcset="https://raw.githubusercontent.com/avdbapi-com/avdbapi-com/main/assets/badge-download-light.svg"><img alt="Download the latest JavCMS release" src="https://raw.githubusercontent.com/avdbapi-com/avdbapi-com/main/assets/badge-download-dark.svg" height="30"></picture></a>

**Or call the API directly.** JSON in the MacCMS format, no key and no sign-up:

```bash
curl "https://avdbapi.com/api.php/provide1/vod?ac=videolist&pg=1&pagesize=20"
```

The answer carries `page`, `pagecount`, `limit`, `total` and a `list` of videos (`vod_id`, `vod_name` and more).
